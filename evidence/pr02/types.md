# PR02 — типы сообщений

## /turtle1/cmd_vel

Тип: `geometry_msgs/msg/Twist`

Назначение: передача команды скорости черепахе.

Структура сообщения включает:
- `linear.x`, `linear.y`, `linear.z`
- `angular.x`, `angular.y`, `angular.z`

В эксперименте использовались:
- `linear.x = 1.0` — движение вперёд;
- `angular.z = 0.5` — поворот.

## /turtle1/pose

Тип: `turtlesim/msg/Pose`

Назначение: текущая позиция, ориентация и скорости черепахи.

Начальная поза:
- x = 5.544444561004639
- y = 5.544444561004639
- theta = 0.0

После команды движения:
- x = 6.509308815002441
- y = 5.796990871429443
- theta = 0.5040000081062317

Изменение координат подтверждает, что команда была получена и выполнена.
